> # 추가 사항

## 목록 휴지통

- 삭제한 프리셋과 커스텀 목록의 카테고리, 기능이 휴지통에 보관됩니다.
- `설정 및 옵션` > `목록 휴지통`에서 종류별로 확인하고 **복원**하거나 **영구 삭제**할 수 있습니다.
- 프리셋은 원래 프로그램으로, 기능은 원래 카테고리로 되돌아갑니다. 원래 카테고리가 없어졌으면 같은 이름으로 다시 만들어 넣습니다.
- 원래 프로그램이 삭제된 프리셋은 복원할 수 없으며, 이유를 안내합니다.

## Grid10 오버레이 방향 설정

- `설정 및 옵션` > `Grid10 오버레이` > `오버레이 방향 설정`에서 오버레이를 90° 단위로 돌릴 수 있습니다.
- Grid10을 세로로 두고 사용할 때 오버레이를 실제 제품이 놓인 방향과 같게 맞출 수 있습니다.
- 방향을 바꿔도 키와 다이얼 이름, 프로그램 이름은 항상 똑바로 읽히도록 표시됩니다.
- 그룹 변경 화면도 같은 방향으로 표시됩니다.

## 커스텀 기능 목록 순서 바꾸기

- 커스텀 기능 목록의 카테고리와 기능 오른쪽 손잡이(≡)를 끌어 순서를 바꿀 수 있습니다.
- 기능을 다른 카테고리 위에 놓으면 그 카테고리로 옮겨집니다.
- 끌고 있는 동안 옮길 항목과 놓을 위치를 강조해서 보여 줍니다.

## 기본 제공 프리셋을 복사해서 수정

- 기본 제공 프리셋을 수정하려고 하면, 막는 대신 **복사해서 작업할지** 묻습니다.
- 확인하면 원래 프리셋 바로 뒤에 복사본을 만들고, 하려던 수정을 복사본에 바로 적용합니다.
- 원래 기본 제공 프리셋은 그대로 유지됩니다.

## 빠른 단축키 입력 개선

- 빠른 단축키 입력 창과 마우스, 다이얼 확장 설정 화면을 새 디자인으로 정리했습니다.
- 빈 키에 새로 만든 기능을 **커스텀 기능 리스트에도 저장**할 수 있습니다. 기본으로 켜져 있으며, 커스텀 목록의 `빠른 단축키` 카테고리에 저장됩니다.
- 키 조합을 운영체제에 맞는 키 모양(`Ctrl`, `⌘` 등)으로 보여 줍니다.

## 기능 검색 미리보기

- 기능 검색창 아래에 최근 검색어와 검색 결과 미리보기를 보여 줍니다.
- 검색 결과에서 검색어와 일치하는 글자를 강조합니다.
- 검색어를 한 번에 지우는 버튼을 추가했습니다.

## 프로그램 추가 목록 개선

- 프로그램 추가 목록에 실행 중인 창 대신 **설치된 프로그램**이 표시됩니다.
- 목록의 프로그램에 마우스를 올리면 실행 파일 경로를 확인할 수 있습니다.

## 기능 목록 사용성 개선

- 기능 목록에 **모두 접기** 버튼을 추가했습니다.
- 폴더를 열고 닫을 때의 움직임을 자연스럽게 다듬었습니다.
- 끌어다 놓을 수 있는 항목에 마우스 커서가 표시됩니다.

> # 수정 사항

## 키 입력 문제 수정

- 같은 글자를 연속으로 입력할 때 일부가 빠지던 문제를 수정했습니다.
- 숫자 패드와 일부 기호 키가 다른 키로 인식되던 문제를 수정했습니다.
- 키를 누른 채 기기 연결이 끊기면 키가 계속 눌린 상태로 남던 문제를 수정했습니다.

## 오버레이 문제 수정

- 기기를 다시 연결하거나 오버레이 설정을 바꾼 뒤 오버레이가 사라지지 않던 문제를 수정했습니다.
- 그룹 변경 모드에서 그룹을 고른 뒤 오버레이가 사라지지 않던 문제를 수정했습니다.
- 프리셋이 없는 프로그램에서 그룹 변경 버튼을 누르면 빈 화면이 뜨던 문제를 수정했습니다. 이제 프리셋이 없다는 안내가 표시됩니다.
- 오버레이 크기가 클수록 위치를 바꿔도 거의 움직이지 않던 문제를 수정했습니다. 위치는 작업 표시줄을 피해 배치됩니다.
- 오버레이 크기를 키운 뒤 프로그램을 바꾸면 글자가 가장 작게 줄어들던 문제를 수정했습니다.
- 두 줄로 나뉘는 이름이 서로 겹쳐 보이던 문제를 수정했습니다.

## 설정 화면 문제 수정

- 프리셋이 없는 프로그램에서 기능을 끌어오면 키와 다이얼이 반응하던 문제를 수정했습니다.
- 아래쪽 키의 툴팁이 창 밖으로 잘리거나, 스크롤 중 툴팁이 위쪽 제목 영역에 겹치던 문제를 수정했습니다.
- 아직 저장하지 않은 프리셋에는 `저장 전` 표시가 붙고, 내보내기에서 제외됩니다.
- 프로그램 추가 목록에서 한 번 추가했다가 뺀 프로그램이 다시 나타나지 않던 문제를 수정했습니다.
- 대화상자를 닫을 때 입력 영역이 먼저 사라진 뒤 닫히던 어색한 움직임을 수정했습니다.

## 기기 연결과 트레이 문제 수정

- 기기 연결이 끊길 때 오류가 발생하던 문제를 수정했습니다.
- 인터넷에 연결되지 않은 상태에서 앱을 실행하면 트레이 아이콘이 나타나지 않던 문제를 수정했습니다.
- 트레이 메뉴의 홈페이지 항목을 정리하고, 지원 센터가 제품 다운로드 페이지로 연결되도록 바꿨습니다.

## Windows 스마트 앱 컨트롤 차단 해결

- Windows의 스마트 앱 컨트롤이 켜져 있으면 일부 구성 요소가 차단되던 문제를 해결했습니다. 앱과 함께 설치되는 구성 요소에 모두 코드 서명을 적용했습니다.

## 안정성과 성능 개선

- 앱의 기반 프레임워크(`Electron` 44)와 주요 구성 요소를 최신 버전으로 업데이트했습니다.
- 기능을 끌어다 놓을 때와 기능 목록을 펼쳐 둘 때의 반응 속도를 개선했습니다.
- `Lightroom Classic`이 꺼져 있을 때 연결을 너무 자주 다시 시도하던 동작을 줄였습니다.
